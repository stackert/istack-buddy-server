# Intent Router Implementation - Part 2

## Overview

This document outlines the implementation of the Intent Router system that enables routing intents to either job executors (for data fetching) or robots (for AI processing). This addresses the need to bypass robots for expensive data operations while maintaining clean separation of concerns.

## Current State Analysis

### ✅ What We Have (Already Implemented):

- **Intent Parsing Service** (`src/common/services/intent-parsing.service.ts`)
- **ChatManager with Intent Parsing** (`src/chat-manager/chat-manager.service.ts`)
- **Robot executeIntent() methods** (AnthropicMarv, SlackyOpenAiAgent)
- **Intent types** (`src/common/types/intent-parsing.types.ts`)
- **Job Queue System** (BullMQ with processors)

### ❌ What's Missing:

- **Intent Handler Registry** - No way to register job executors as intent handlers
- **Job Intent Executors** - Services that handle data fetching before calling robots
- **Intent Router Service** - Routes intents to handlers OR robots
- **ChatManager Integration** - Still routes directly to robots only

## Problem Statement

**Current Flow (Limited):**

```
User Message → Intent Parsing → Robot Selection → Robot.executeIntent()
```

**Desired Flow (Flexible):**

```
User Message → Intent Parsing → Intent Router → Job Executor OR Robot → Response
```

**Goals:**

- Avoid costly robot calls for data fetching operations
- Enable "good-old-fashion code" to manipulate data before robot processing
- Maintain clean separation: data fetching vs AI processing
- Support complex workflows: job → post-processing → robot → post-processing

### **2. Intent Router Service**

**File**: `src/common/services/intent-router.service.ts`

```typescript
import { Injectable, Logger } from '@nestjs/common';
import { IntentHandler } from '../interfaces/intent-handler.interface';
import { IntentParsingResponse } from '../types/intent-parsing.types';
import { IStreamingCallbacks } from '../../robots/types';
import { RobotService } from '../../robots/robot.service';

@Injectable()
export class IntentRouterService {
  private readonly logger = new Logger(IntentRouterService.name);
  private readonly intentHandlers = new Map<string, IntentHandler>();

  constructor(private readonly robotService: RobotService) {}

  /**
   * Register an intent handler for specific intents
   */
  registerHandler(intent: string, handler: IntentHandler): void {
    this.intentHandlers.set(intent, handler);
    this.logger.log(`Registered intent handler for: ${intent}`);
  }

  /**
   * Route intent to appropriate handler or robot
   */
  async routeIntent(
    intentResult: IntentParsingResponse,
    callbacks: IStreamingCallbacks,
  ): Promise<void> {
    const { intent, intentData, robotName } = intentResult;

    // Check if we have a specialized intent handler
    const handler = this.intentHandlers.get(intent);

    if (handler) {
      this.logger.debug(`Routing intent '${intent}' to intent handler`);
      await handler.executeIntent(intentData, callbacks);
    } else {
      this.logger.debug(`Routing intent '${intent}' to robot: ${robotName}`);
      // Fallback to robot (existing behavior)
      const robot = this.robotService.getRobotByName(robotName);
      if (!robot) {
        throw new Error(`Robot ${robotName} not found`);
      }
      await robot.executeIntent(intentData, callbacks);
    }
  }

  /**
   * List all registered intent handlers
   */
  getRegisteredIntents(): string[] {
    return Array.from(this.intentHandlers.keys());
  }
}
```

### **5. Intent Handler Registry Service**

**File**: `src/common/services/intent-handler-registry.service.ts`

```typescript
@Injectable()
export class IntentHandlerRegistryService implements OnModuleInit {
  constructor(
    private readonly intentRouter: IntentRouterService,
    private readonly sumoReportExecutor: SumoReportJobExecutor,
    // Add other executors as they're created
  ) {}

  onModuleInit() {
    // Auto-register all intent handlers
    this.registerHandler(this.sumoReportExecutor);
  }

  private registerHandler(handler: IntentHandler) {
    const supportedIntents = handler.getSupportedIntents();
    supportedIntents.forEach((intentConfig) => {
      this.intentRouter.registerHandler(intentConfig.intent, handler);
    });
  }
}
```
